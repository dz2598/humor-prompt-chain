# Campus LOL Prompt Chain Lab

Week 8 standalone prompt-chain management tool.

## Features

- Superadmin-only Google authentication
- Create, update, and delete prompt chains
- Create, update, delete, and drag-to-reorder prompt steps
- Execute a chain with Gemini 3.1 Flash-Lite
- View outputs generated by a specific chain
- Light, dark, and system themes

## Local setup

Copy the same Supabase and Gemini environment values used by the Campus LOL projects into `.env.local`, then run:

```bash
npm ci
npm run dev
```

The tool uses the existing `prompt_chains`, `prompt_chain_steps`, `generation_requests`, `llm_responses`, and `profiles` tables in the shared Supabase project.
